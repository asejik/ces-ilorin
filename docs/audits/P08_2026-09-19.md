## Executive Summary

A technical SEO and discoverability audit was performed on the Citizens Elementary School (CES) platform. The application is hosted on Vercel with Next.js 14 App Router, serving pages with fast initial server-rendered HTML shells ($< 115\text{ kB}$ First Load JS). Missing pages properly return `HTTP 404 Not Found`, and heading hierarchies (`<h1>` $\rightarrow$ `<h2>`) are semantic and clean.

However, the audit revealed significant discoverability and social sharing gaps:
1. **Broken Social & WhatsApp Previews**: The site completely lacks Open Graph (`og:*`) and Twitter Card metadata. Sharing links on WhatsApp, Facebook, LinkedIn, or X results in a blank fallback with no preview image or description.
2. **Missing `robots.txt` and XML Sitemap**: Spiders (Googlebot, Bingbot) receive `404 Not Found` for both `/robots.txt` and `/sitemap.xml`.
3. **Missing Canonical Tags & Duplicate Titles**: All routes share the exact same root fallback `<title>` ("CES Portal | Citizens Elementary School"), and no canonical `<link rel="canonical">` is emitted.
4. **No JSON-LD Structured Data**: Search engines cannot parse the school as an `EducationalOrganization` or its syllabus as a discipleship `Course`.
5. **Exposed Login / Admin Paths**: Private routes lack explicit `noindex, nofollow` robot directives.

## Audit Findings & Evidence

### Section 1: Rendering (Raw HTML Analysis)

#### [Finding 1.1 — HIGH] Raw HTML Missing Open Graph, Twitter Cards, and Canonical Tags
- **Severity**: HIGH
- **Files Affected**: [`src/app/layout.tsx`](file:///home/asejik/projects/ces/src/app/layout.tsx)
- **Evidence**:
  Inspecting the initial server-rendered HTML stream via `curl -s http://localhost:3000/` reveals only:
  ```html
  <title>CES Portal | Citizens Elementary School</title>
  <meta name="description" content="Academic Management and Discipleship Training Portal for Citizens of Light Church, Ilorin" />
  <link rel="shortcut icon" href="/favicon.ico" />
  <link rel="icon" href="/icon.svg" />
  <link rel="apple-touch-icon" href="/icon.svg" />
  ```
  The raw HTML contains **zero** Open Graph tags (`og:title`, `og:image`, `og:description`, `og:url`), zero Twitter Card tags, and zero canonical link elements.
- **Impact**: Social platforms, messaging apps (especially **WhatsApp**, which does not execute client JavaScript), and search crawlers see an unbranded URL preview with no preview card.
- **Verification Tool**: Facebook Sharing Debugger (`https://developers.facebook.com/tools/debug/`), LinkedIn Post Inspector (`https://www.linkedin.com/post-inspector/`).

---

### Section 2: Crawling and Indexing

#### [Finding 2.1 — HIGH] Missing `robots.txt` and XML Sitemap
- **Severity**: HIGH
- **Files Affected**: Missing `src/app/robots.ts` and `src/app/sitemap.ts`
- **Evidence**:
  ```bash
  curl -I http://localhost:3000/robots.txt   # Returns HTTP 404 Not Found
  curl -I http://localhost:3000/sitemap.xml  # Returns HTTP 404 Not Found
  ```
- **Impact**: 
  - Search crawlers waste crawl budget attempting to access internal paths.
  - Spiders cannot discover canonical public routes or detect lastmod updates.
  - Search Console property cannot ingest the sitemap.
- **Verification Tool**: Google Search Console Sitemaps tool.

#### [Finding 2.2 — MEDIUM] Private Administrative & Auth Routes Lack `noindex` Directives
- **Severity**: MEDIUM
- **Files Affected**: [`src/app/admin/layout.tsx`](file:///home/asejik/projects/ces/src/app/admin/layout.tsx) (missing), [`src/app/(auth)/login/page.tsx`](file:///home/asejik/projects/ces/src/app/%28auth%29/login/page.tsx)
- **Evidence**:
  While unauthenticated users are redirected from `/admin/*` via middleware, the `/login` route is public and renders without a `noindex` robots meta tag. Spiders can index the login screen into Google search results.
- **Impact**: Low-quality internal login screens pollute public search results instead of core educational content.
- **Verification Tool**: Google Search Console URL Inspection.

#### [PASS] 404 Status Code Accuracy
- Missing routes return an authentic `HTTP 404 Not Found` status rather than a soft-404 `200 OK`. Verified with `curl -I http://localhost:3000/non-existent-random-page-xyz`.

---

### Section 3: Canonicals and URL Consistency

#### [Finding 3.1 — MEDIUM] Absence of Self-Referencing Canonical URLs
- **Severity**: MEDIUM
- **Files Affected**: [`src/app/layout.tsx`](file:///home/asejik/projects/ces/src/app/layout.tsx)
- **Evidence**:
  No `<link rel="canonical" href="..." />` tag exists anywhere in the rendered HTML. Next.js `metadataBase` is unset.
- **Impact**: Search engines may consider URL variants (`?cohort=Regular`, trailing slash variants, or query parameters) as duplicate content, diluting page authority.
- **Verification Tool**: View Page Source, search for `rel="canonical"`.

---

### Section 4: On-Page Basics

#### [Finding 4.1 — MEDIUM] Duplicate Titles and Descriptions Across Public Routes
- **Severity**: MEDIUM
- **Files Affected**: [`src/app/register/page.tsx`](file:///home/asejik/projects/ces/src/app/register/page.tsx), [`src/app/assess/page.tsx`](file:///home/asejik/projects/ces/src/app/assess/page.tsx), [`src/app/attendance/page.tsx`](file:///home/asejik/projects/ces/src/app/attendance/page.tsx)
- **Evidence**:
  Because public pages are `'use client'` components, they do not export route-specific metadata. Visiting `/register` or `/assess` results in the same generic title: "CES Portal | Citizens Elementary School".
- **Impact**: Google Search Console flags "Duplicate title tags". Search result snippets do not explain what action a user takes on that specific page (e.g. "Register for 2026 Cohort" vs "Student Assessment Portal").
- **Verification Tool**: Google Search Console Page Indexing Report.

#### [PASS] Heading Structure and Hierarchy
- Every public route has a single, semantic `<h1>` tag followed by logical `<h2>` and `<h3>` tags.
  - `/`: `<h1 className="...">Equipping Believers with Kingdom Truth & Integrity</h1>`
  - `/register`: `<h1>Citizens Elementary School (CES)</h1>`
  - `/assess`: `<h1>Candidate Verification</h1>`
  - `/attendance`: `<h1>Class Attendance & Delivery Rating</h1>`

### Section 5: Structured Data (JSON-LD)

#### [Finding 5.1 — MEDIUM] Missing Schema.org Structured Data for Educational Institution & Curriculum
- **Severity**: MEDIUM
- **Files Affected**: [`src/app/layout.tsx`](file:///home/asejik/projects/ces/src/app/layout.tsx), [`src/app/page.tsx`](file:///home/asejik/projects/ces/src/app/page.tsx)
- **Evidence**:
  Raw HTML contains zero `<script type="application/ld+json">` elements.
- **Impact**: Google cannot display Rich Snippets for the school or recognize the course program in Knowledge Graph entity associations for "Citizens of Light Church, Ilorin".
- **Appropriate Schema Types**:
  1. `EducationalOrganization`: Outlining the church school, official name, address in Ilorin, and parent church.
  2. `Course`: Describing the Citizens Elementary School Discipleship Program and its 8 modules.
- **Verification Tool**: Google Rich Results Test (`https://search.google.com/test/rich-results`), Schema.org Validator (`https://validator.schema.org/`).

---

### Section 6: Social and Link Previews (WhatsApp & Social Sharing)

#### [Finding 6.1 — HIGH] Broken WhatsApp and Social Media Link Unfurling
- **Severity**: HIGH
- **Files Affected**: [`public/og-image.png`](file:///home/asejik/projects/ces/public/og-image.png) (generated, but not referenced in HTML metadata)
- **Evidence**:
  Social platforms parse Open Graph meta properties. Without `og:image`, `og:title`, and `og:description` in the initial server response:
  - **WhatsApp**: Displays only a plain text link without a preview box or thumbnail image.
  - **X (Twitter)**: Renders no card summary.
  - **Facebook / LinkedIn**: Fails to generate an article card.
- **Remediation**: Configure high-resolution Open Graph image (`og-image.png`, 1200x630, 33.6 kB) in root metadata.

---

### Section 7: AI Search Visibility

#### [Finding 7.1 — LOW] Missing Plain-Text `llms.txt` Directory for AI Search Agents
- **Severity**: LOW
- **Files Affected**: Missing `public/llms.txt`
- **Description**: Emerging AI search engines (Perplexity, ChatGPT Search, Bing Copilot) utilize `llms.txt` to quickly index markdown summaries of curriculum, cohort formats, and admission policies.
- **Remediation**: Provide a concise `public/llms.txt` summarizing the institution and syllabus.

## Actionable Remediation Plan (6 Code Fixes)

1. **Root Layout Metadata & Social Cards (F-SEO-01, F-SEO-03)**:
   - Configure `metadataBase: new URL('https://ces.citizensoflightchurch.org')` in `src/app/layout.tsx`.
   - Add comprehensive `openGraph` and `twitter` properties referencing `/og-image.png` (1200x630).
   - Set default self-referencing canonical structure (`alternates: { canonical: './' }`).
2. **App Router `robots.ts` (F-SEO-02)**:
   - Generate `robots.txt` allowing `/` and disallowing `/admin/`, `/api/`, and `/login`.
   - Point to `https://ces.citizensoflightchurch.org/sitemap.xml`.
3. **App Router `sitemap.ts` (F-SEO-02)**:
   - Enumerate public pages (`/`, `/register`, `/assess`, `/attendance`) with weekly change frequency and priority weighting.
4. **Structured Data JSON-LD (F-SEO-04)**:
   - Inject Schema.org `EducationalOrganization` and `Course` JSON-LD into `src/app/layout.tsx`.
5. **Private Route Indexing Protection (F-SEO-05)**:
   - Create `src/app/admin/layout.tsx` (or update metadata) setting `robots: { index: false, follow: false }`.
   - Add `noindex` metadata to `src/app/(auth)/login/layout.tsx`.
6. **AI Agent Directory (F-SEO-06)**:
   - Create `public/llms.txt` with plain-text curriculum facts and admissions information.
