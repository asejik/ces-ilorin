## 4. Findings in detail

### P08-01 · HIGH · Missing `og:image` on `/register`
- **Evidence (raw HTML)**: home `og:image = https://ces.citizensoflightchurch.org/og-image.png` ✅ (1200 × 630 px, 33,646 bytes, absolute URL). `/register`, `/assess`, `/attendance`: `og:image` **(none)**; only `twitter:image` is inherited.
- **Cause**: each route layout (e.g. `src/app/register/layout.tsx`) defines its own `openGraph` object, which **replaces** the parent's `openGraph.images` in Next.js metadata merging.
- **Impact**: WhatsApp, Facebook and LinkedIn read `og:image`; the registration link — the page you will share most — shows a plain text preview.
- **Fix**: add `images: [{ url: '/og-image.png', width: 1200, height: 630, alt: '…' }]` to every route-level `openGraph` (or a shared helper). After deploying, refresh caches (section 6).
- **Self-check**: View Page Source of `/register` → search for `og:image`.

### P08-02 · MEDIUM · Robots, sitemap and indexing disagree
- **Evidence**: `robots.txt` → `Disallow: /assess` (but `/attendance` allowed). `sitemap.xml` lists `/`, `/register`, `/assess`, `/attendance`. Neither `/assess` nor `/attendance` has a `noindex` meta tag; both have self-referencing canonicals.
- **Impact**: Search Console would report "Submitted URL blocked by robots.txt" for `/assess`; `/attendance` (a student check-in form) could be indexed and surfaced in Google. A robots block does not remove pages from results and prevents Google from seeing a noindex.
- **Fix**: set `robots: { index: false, follow: false }` in the `/assess` and `/attendance` layouts, remove both from `sitemap.ts`, and delete `Disallow: /assess` (keep `/admin/`, `/api/`, `/login`, `/certificate/`, `/register/success`; the latter three already carry `noindex`). Keep `/` and `/register` indexable and in the sitemap. (If the church wants these found in search, say so and I will keep them indexable instead.)

### P08-03 · MEDIUM · `llms.txt` states wrong facts
Compared with the code and rules (`academic.ts`, curriculum, registration form):
| llms.txt says | The app actually has |
|---|---|
| "Saturday Cohort" | **Regular** cohort (weekdays) and Sunday cohort |
| Honours: Distinction ≥ 85, "Honours 70–84", Merit 50–69 | Distinction ≥ 85, Merit ≥ 75, Pass ≥ 50, Below Pass < 50 |
| "100% attendance across both scheduled class dates (Day 1 & Day 2)" | Attendance in *Elementary Principles* and *Membership & Vision Class* |
| "Module 8: Prayer & Fasting" | "Prevailing Prayer & Intercession" |
| "2 intensive lecture days" | unverifiable from the product |
- `llms.txt` is an optional, unproven convention, but a wrong file misinforms AI search tools. **Fix**: correct it from the real rules, have the church confirm the oversight/leadership wording and schedule, or delete the file.

### P08-04 · LOW · Sitemap dates
- `src/app/sitemap.ts` sets `lastModified: new Date()` for all URLs, so every URL claims it changed at request time (live output: `2026-10-22T13:25:21Z` for all). Search engines learn to ignore it. **Fix**: use fixed dates updated when content changes.

### P08-05 · LOW · Structured data
- JSON-LD parses as valid JSON with two types: `EducationalOrganization` (name, alternateName, url, logo, image, parent `Church`, address locality Ilorin / Kwara State / NG) and `Course` (name, description, provider). Facts match the visible site. Improvements: provide a PNG logo (the SVG `icon.svg` is used); add `hasCourseInstance` (start dates, mode) only when real dates exist; add `sameAs` only for real social profiles; no `LocalBusiness`/address/phone/hours/reviews are invented — keep it that way.

### P08-06 · LOW · Private pages inherit home previews
- `/login` and `/certificate/[id]` show the home `og:title`, `og:url` and `og:image`. They are `noindex`, so low impact, but sharing a certificate link would preview the generic site card. Acceptable; optionally give the certificate page its own neutral preview.

### P08-07 · MEDIUM · Production configuration (to verify after deployment)
- `robots.ts`/`sitemap.ts` use `NEXT_PUBLIC_APP_URL` (falls back to the production domain). Set it in Vercel to `https://ces.citizensoflightchurch.org` **without a trailing slash**; never leave `localhost` in production.
- Preview deployments (`*.vercel.app`) should not be indexable: Vercel's deployment protection may cover it, but the app does not enforce it. Add an `X-Robots-Tag: noindex` for non-production (`VERCEL_ENV !== 'production'`).
- Redirect `http→https`, `www→apex` (or the reverse) permanently so canonicals match; Vercel handles this when the domain is configured — verify.

### P08-08 · LOW · Wrong cohort wording
- `/attendance` meta description: "Confirm attendance for Saturday and Sunday cohorts…". Use "Regular and Sunday cohorts".
